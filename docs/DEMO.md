# Demo video script (about 3–5 minutes)

1. **Intro (10 s):** "This is FormPilot, tested on the **NVIDIA** Workday form: Senior HPC Storage Engineer."
2. **Settings (15 s):** open Settings, show "Key works" and the model picker. Don't show the key itself.
3. **Resume (45 s):** Resume tab → upload a PDF → "Gemini is reading…" → the parsed profile appears. Fix one field to show autosave.
4. **Answers (30 s):** answer the yes/no questions and "How did you hear". Point out that EEO defaults to "Decline".
5. **Autofill (2–3 min):** open the job posting → Autofill tab → **Fill all pages**.
   - It clicks Apply → Apply Manually and pauses at sign-in. **Sign in yourself** and say that FormPilot never touches login.
   - Let it fill My Information, My Experience (jobs, schools, resume upload), Application Questions, Voluntary Disclosures and Self Identify. Show the side-panel report: filled ✓, AI answers with confidence, suggestions with **Use**, and flagged consent boxes.
   - Tick any consent box yourself and press Fill all pages again if it paused.
6. **Review and submit (30 s):** at Review, scroll the Workday page and the side-panel list → **Confirm and submit…** → **Yes, submit** → "Submitted".
